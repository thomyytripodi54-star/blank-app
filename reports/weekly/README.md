# Weekly reports

Output of the `/weekly-market-email` pipeline lands here, one pair of files per run:

- `<YYYY-MM-DD>-market-analysis.md` — the `market-analyst` subagent's research report.
- `<YYYY-MM-DD>-email.md` — the `email-writer` subagent's synthesized email based on it.

Committed so the pick history and rationale stay auditable over time.
