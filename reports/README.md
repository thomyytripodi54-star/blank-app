# reports/

Archivo histórico de los reportes semanales generados por el skill `weekly-stock-report`. Cada corrida crea una carpeta `YYYY-MM-DD/` con el `reporte.html` enviado ese día como borrador de Gmail.

Este contenido generado no se versiona en git (ver `.gitignore`) — es historial local para consulta rápida, no parte del código del proyecto.
